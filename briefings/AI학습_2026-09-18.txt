📚 오늘의 학습 주제 : 실습 2일차 · 트리거·액션 후보를 노코드 도구 화면에 옮기기 — Zapier 실제 설정값으로 필드 매핑하기 (2026-09-18)

📌 어제 배운 내용과의 연결
어제는 반복 빈도·규칙 서술·재량 판단이라는 세 가지 질문으로 여러분의 업무 중 자동화 후보(매주 금요일 부서 회의자료 취합)를 하나 골랐으니, 오늘은 그 후보를 실제 노코드 도구 화면에 옮겨 비서에게 정확히 어느 칸에 무엇을 적을지 알려주는 단계입니다.

🎯 오늘 배울 개념
트리거가 물어온 데이터 조각을 액션의 빈칸에 정확히 연결하는 필드 매핑(Field Mapping, 이전 단계의 결과값을 다음 단계 입력값에 이어 붙이는 작업)

━━━━━━━━━━━━━━━━━━━━

비서에게 "회의자료가 오면 폴더에 저장하고 담당자에게 알려라"라고 말로만 시키면 비서는 파일을 어디서 가져와야 할지, 담당자 이름을 어디서 확인해야 할지 알 수 없습니다. 그래서 실제로는 양식지를 하나 만들어 줍니다. "첨부파일 칸에는 방금 받은 메일의 첨부파일을 넣어라, 담당자 칸에는 방금 받은 메일의 보낸 사람 이름을 넣어라"처럼 빈칸 하나하나에 어디서 값을 가져올지 표시해 주는 것입니다. 노코드 도구 화면도 똑같습니다. 트리거 단계가 메일을 받아오면, 그 메일 안에는 제목·보낸 사람·첨부파일 같은 여러 데이터 조각이 들어 있습니다. 액션 단계의 빈칸에 이 조각들을 하나씩 끌어다 연결하는 작업이 필드 매핑입니다. 화면에서는 보통 파란색이나 회색 태그로 "1. 첨부파일", "1. 보낸 사람"처럼 표시되는데, 이 태그를 빈칸에 넣으면 실행될 때마다 그날그날 실제 값으로 자동 치환됩니다. 반대로 태그 대신 그냥 글자를 직접 타이핑하면, 그것은 매번 똑같은 고정값으로만 나갑니다. 즉 화면을 채우는 일은 단순 타이핑이 아니라, "이 칸은 고정값인가 트리거가 물어온 값인가"를 구분하는 작업입니다.

🛠 실전 연결
심화 9일차에서 뜯어본 Zap의 트리거·액션 구조를 기억한다면, 오늘은 그 구조에 실제 값을 채워 넣는 차례입니다. 여비 계산기에서도 "카카오 로그인이 완료되면 여행 금액을 자동으로 입력한다"는 규칙 뒤에는 실제로 카카오 로그인 응답값 중 어떤 필드(예: 사용자 이름, 인증 토큰)를 여행 금액 입력 화면의 어떤 변수에 연결할지 정하는 필드 매핑 작업이 있었습니다. 크롬 확장이 페이지의 특정 버튼 클릭을 감지해 서버로 데이터를 보낼 때도, "클릭된 버튼의 텍스트"라는 값을 서버 요청의 정해진 자리에 정확히 끼워 넣는 것과 같은 원리입니다.

🔍 예시
어제 고른 업무(매주 금요일 회의자료 취합)를 Zapier 화면에 옮기면 아래와 같은 모습이 됩니다.

  • 1단계 트리거 : Gmail — New Email Matching Search
    • Search string 칸 : subject:회의자료
  • 2단계 액션 : Google Drive — Upload File
    • Folder 칸 : 정책기획과 회의자료 폴더
    • File 칸 : {{1. Attachment}}  ← 트리거가 받아온 첨부파일 태그
  • 3단계 액션 : Slack — Send Channel Message
    • Channel 칸 : #정책기획과-공지
    • Message 칸 : {{1. From Name}}님이 회의자료를 업로드했습니다 — {{1. Subject}}

여기서 {{1. Attachment}}, {{1. From Name}}처럼 숫자와 점으로 시작하는 부분이 바로 필드 매핑 태그이며, "1"은 1단계 트리거에서 가져온 값이라는 뜻입니다.

📝 오늘의 한 줄 정리
노코드 도구 화면을 채우는 일은 빈칸에 글자를 타이핑하는 것이 아니라, 트리거가 물어온 데이터 조각을 액션의 정확한 자리에 연결하는 필드 매핑 작업입니다.

🙋 초보자가 자주 헷갈리는 점
화면의 빈칸에 태그 대신 눈에 보이는 예시 값(예: "회의자료.pdf")을 그대로 타이핑해 넣는 실수가 흔합니다. 그러면 첫 실행 때는 잘 작동하는 것처럼 보이지만, 다음번에 다른 파일이 와도 계속 같은 이름으로만 저장되거나 전송됩니다. 빈칸 안의 값이 파란 태그(동적 값)인지 검은 글자(고정 값)인지 항상 확인해야 합니다.

💬 내일 예고
내일은 오늘 채운 화면이 실제로 실패할 수 있는 경우들(메일에 첨부파일이 없거나, 폴더 권한이 없는 경우 등)을 미리 점검하고, 실패했을 때 어떻게 대비할지 설계해 봅니다.
